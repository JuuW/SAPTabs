# SAP Tabs

一个 macOS 菜单栏小工具:在屏幕顶部浮一条**浏览器式页签栏**,列出当前打开的所有 SAP GUI 会话窗口,点一下即可切换,再也不用在一堆长得一模一样的 SAP 窗口里挨个翻找。

![placeholder](https://via.placeholder.com/800x60?text=SAP+Tabs+Preview)

## 功能特性

- **一条浮动页签栏** —— 常驻屏幕顶部、水平居中,仅在 SAP GUI 处于前台时自动显示,切到别的应用就隐藏,不打扰。
- **一眼看清所有会话** —— 把分散的 SAP 窗口聚合成页签。同一个系统的会话自动归为一组,组首显示系统 ID(如 `DWC`),组内各页签显示当前事务码(如 `/SCWM/MON`)。
- **组内按事务码字母排序** —— 同系统的页签按 TCode 字母序排列,位置可预期,好找。
- **TCode 收藏菜单** —— 页签栏最左侧的下拉菜单收藏常用事务码,支持多级文件夹分组,点一下即可在当前 SAP 会话里打开对应事务。
- **单击秒切** —— 点页签立刻把对应 SAP 窗口抬到最前,零延迟,点击时不抢占焦点。
- **当前窗口高亮** —— 当前聚焦的会话页签高亮显示;即便多个窗口标题完全相同也不会误高亮。
- **放不下自动收纳** —— 页签过多时,放不下的自动收进右端下拉菜单,不挤爆屏幕。
- **右键关闭** —— 在页签上右键即可关闭对应 SAP 会话窗口。
- **极轻量** —— 原生 Swift + SwiftUI + AppKit,无后台服务、无网络请求,仅通过系统辅助功能 API 读取窗口信息。

## 环境要求

- macOS 13 (Ventura) 或更高版本
- 已安装 **SAP GUI for Java 8.10**(进程名 `SAPGUI`、bundle id `com.sap.platin`)
- 构建需要 Xcode 命令行工具(`xcode-select --install`),内含 Swift 工具链

> 注:当前识别逻辑针对 SAP GUI for Java 8.10。换其它版本或 SAP GUI for HTML 可能需要调整进程名/标题识别规则。

## 安装

### 方式一:自行构建(推荐)

1. 克隆仓库并进入目录:

   ```bash
   git clone <本仓库地址> SAPTabs
   cd SAPTabs
   ```

2. 运行打包脚本,会编译并生成可双击运行的 `SAP Tabs.app`:

   ```bash
   ./build.sh
   ```

3. 把生成的 `SAP Tabs.app` 拖进「应用程序」文件夹(可选),然后双击运行:

   ```bash
   open "SAP Tabs.app"
   ```

### 方式二:直接拿到打好包的 .app

如果别人已经用 `build.sh` 打好了 `SAP Tabs.app`,把这个 `.app` 拷到你的电脑,双击即可运行(首次运行需按下方授权辅助功能)。

> 应用没有经过 Apple 公证,首次打开若被 Gatekeeper 拦下,在「系统设置 → 隐私与安全性」里点「仍要打开」,或右键 .app → 打开。

## 首次运行:授权「辅助功能」

本工具靠系统辅助功能(Accessibility)API 读取和切换 SAP 窗口,**必须授权才能工作**。

1. 首次运行时,页签栏会提示「需要辅助功能权限」,点「去授权」。
2. 在弹出的「系统设置 → 隐私与安全性 → 辅助功能」里,打开 **SAP Tabs** 的开关。
3. 回到应用,页签栏即开始正常列出 SAP 窗口。

授权是按「签名身份 + 可执行文件」记录的。本项目的 `build.sh` 用本地自签名证书签名,因此**重新构建后授权依然有效**,无需每次重授。

## 使用

- 打开任意 SAP GUI 会话,页签栏会自动出现在屏幕顶部。
- **单击**页签 → 切到对应会话窗口。
- **右键**页签 → 关闭该会话。
- 切到非 SAP 应用时,页签栏自动隐藏;切回时再次出现。
- 可从菜单手动停用「自动显示」。

## TCode 收藏菜单

页签栏最左侧有一个向下三角按钮,点开是你收藏的事务码列表,用来快速在当前会话里打开常用事务。

- **列表排序** —— 每一级都是文件夹排在前、事务码排在后,各自按字母序。
- **点事务码执行** —— 点击某个 TCode,即把它填入**当前前台会话**的 OK Code 输入框并回车执行:
  - 默认用 `/o` 前缀(另开一个新窗口打开该事务);
  - 按住 **Option(Alt)** 点击则用 `/n` 前缀(在当前窗口切换到该事务)。
- **Add TCode** —— 每一级菜单末尾的 `Add TCode`,会抓取当前前台会话正在运行的事务码,加入到该级;读不到(停在登录屏/主屏)或已存在时会提示。
- **Add Folder** —— 每一级菜单末尾的 `Add Folder`,弹框输入名称即可在该级新建子文件夹,用来给事务码分组;重名会提示。

收藏数据保存在你的用户主目录下的 `~/.saptabs_tcodes.json`。

## 卸载

退出应用并删除 `.app` 即可;如需清理授权,在「系统设置 → 隐私与安全性 → 辅助功能」里移除 SAP Tabs。

```bash
pkill -x SAPTabs
rm -rf "SAP Tabs.app"
rm -f ~/.saptabs_tcodes.json   # 如需一并清掉 TCode 收藏
```
